# Climate-image seminar

Open **https://dpfu.github.io/sortboard/?study=climate-images** on the seminar computer in a desktop browser. Import the separately provided `climate-images.sortboard.zip` using **Import project**. It contains the twelve images, both tasks and the prepared grid. No account, local installation or configuration is needed. Tasks and reflection questions are German; the general app controls remain English. The teaching images are not hosted on GitHub Pages.

## Prepare and hand over

1. Copy the project ZIP to the seminar computer, open the link before connecting the projector, and import it once. Later visits reopen the matching local project. For a completed practice run, choose **New participant**; earlier results remain in their own project. An interrupted run offers **Resume round**.
2. Assign one participant and two companions. One companion follows the reasons and asks open questions after each round; the other observes interaction and revisions. The [printable companion guide](https://dpfu.github.io/sortboard/studies/climate-images-guide.html) contains the roles and steps.
3. Select **Start sorting**. The exercise starts in full screen where supported. Hand over the computer: the current statement stays visible throughout the sort, and **Controls** explains the gestures in German.

## Participant sequence

1. **Importance:** “Dieses Bild gibt mir das Gefühl, dass der Klimawandel wichtig ist.” Place all twelve images, then select **Finish round**. Discuss the extremes and difficult decisions. Use **Replay round 1** beside the result to revisit a moment before continuing.
2. Select **Continue to round 2**. The same images are reshuffled on an empty grid. The first result and its recording remain saved.
3. **Ability to act:** “Dieses Bild gibt mir das Gefühl, dass ich etwas gegen den Klimawandel tun kann.” Complete and discuss this sort too.
4. Use **Choose images** to select up to four images to discuss. Select a thumbnail to see the image enlarged beside both distributions; its position is highlighted in each. Both task statements remain visible. **Discussion prompts** opens the comparison questions. These are descriptive placements, not Q-method factors or an effect estimate.
5. Use **Replay round 1 / 2** to revisit a hesitation or revision. **Play recording**, **Pause**, and the timeline control playback; **Back to study** returns to the discussion or final comparison.
6. Select **Export study**, check the downloaded ZIP, and hand it to the instructor using the course's agreed channel. The archive contains both recordings, task statements, images, image credits and `results.csv`. Importing it restores the study in SortBoard.

The group can complete this sequence without the instructor. **Pause** preserves an unfinished round; reloading the same link offers **Resume**. Work is stored in that browser, not submitted to GitHub or the instructor. Export before leaving a shared computer or clearing its browser data. Recording captures sorting movements, not audio or a screen video. Load the app with an internet connection; an offline reload is not guaranteed.

## Material

This is an independent twelve-image teaching adaptation of Metag et al. (2016), DOI [10.1177/1075547016635181](https://doi.org/10.1177/1075547016635181). The original study used forty images and nine positions. This exercise uses seven positions from −3 to +3, with capacities **1 / 1 / 2 / 4 / 2 / 1 / 1**. Rows are additional places at the same score. No Q-factor analysis is implemented.

Images retain their source rights, separate from the app's MIT licence. Credits and rights are available inside the exercise and every project export; keep them with copies. The source material's contact sheet is not a stimulus. No teaching images, article PDF or participant results are included in the public site.
